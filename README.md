# EduSpark – Responsive Landing Page

## About the Project
EduSpark is a fictional online educational platform designed to help college students improve their skills through online courses and practical learning.

## Target Audience
College students aged 18–25.

## Tools Used
- Figma
- Figma AI

## Design Features
- Header with navigation and CTA button
- Hero section with illustration
- Three feature cards
- Call-to-action section
- Footer

## Design Choices
The design uses purple, white and dark navy colors to create a modern and professional appearance. Clean typography and consistent spacing improve readability.
